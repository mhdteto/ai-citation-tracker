# Security

Do not include confidential answers in a public report. JSON and HTML retain complete input text. Treat imported datasets as untrusted and inspect citations before opening them; syntactic URL validation is not a reputation or malware check.

Report vulnerabilities privately via [the maintainer's contact page](https://mohammedteto.com/contact/) with a minimal synthetic reproduction and affected version. If GitHub private vulnerability reporting is enabled, that is also suitable. Do not post live private data, tokens or exploit payloads containing third-party information. V1 is maintained on a best-effort basis; no response SLA is promised.

Output must be written in a directory you control. File collision checks are not a defense against concurrent filesystem races. This program never fetches citation URLs.

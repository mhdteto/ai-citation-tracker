# Contributing

Use Python 3.10+ and the standard library. Run `python3 -m unittest discover -s tests -v` and regenerate the example using the README command. Confirm that a second generation leaves no diff. Add a failing regression test before changing parsing, counting, export or collision behavior. Keep collection and network access outside this tool. Do not commit real personal data, proprietary answers, credentials or captures.

Explain changes to denominators or normalization explicitly. Keep the schema and methodology consistent. By contributing code you agree to MIT; documentation/example/artwork contributions use CC BY 4.0. Open a pull request with the behavior change and verification performed. Do not send sensitive security details in public issues.

## Choose a contribution route

- [Bug or documentation error](https://github.com/mhdteto/ai-citation-tracker/issues/new?template=bug_report.yml): include a release tag or commit and a minimal public/fictional reproducer.
- [Feature request](https://github.com/mhdteto/ai-citation-tracker/issues/new?template=feature_request.yml): state the task, example and proposed behavior.
- [Source or methodology proposal](https://github.com/mhdteto/ai-citation-tracker/issues/new?template=source_proposal.yml): provide the specific claim, publisher, dates, market, relationship and limits.

Run the documented validation and preserve the distinction between observed, supplied, inferred and unknown. See the [connected fictional workflow](https://github.com/mhdteto/authority-architecture-system/tree/main/examples/fictional-workflow) for an example.
